# Mossuri Whitelist

Vite + React one-page whitelist site prepared for Vercel.

## Run locally
npm install
npm run dev

## Build
npm run build

## Deploy
Push this folder to GitHub, import the repository into Vercel, and deploy.

## Assets
- `public/assets/logo.png` — transparent Mossuri logo
- `public/assets/artwork/` — uploaded Mossuri artwork

## Note
The whitelist form UI is wired for the supplied tasks. The submit handler currently shows a local success state; connect it to your chosen backend/Google Apps Script endpoint before launch.
